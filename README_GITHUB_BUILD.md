# K-Dilebo Trader — phone-only build

This project includes a GitHub Actions workflow that builds a debug APK in the cloud.

After uploading the project files to your GitHub repository:
1. Open **Actions**.
2. Choose **Build K-Dilebo Trader APK**.
3. Run the workflow if it did not start automatically.
4. Open the completed run.
5. Under **Artifacts**, download **KDileboTraderApp-debug**.
6. Extract it and install `app-debug.apk` on your Android phone.

Important: this is still a dashboard prototype. It is not connected to MT5 and does not place live trades.
